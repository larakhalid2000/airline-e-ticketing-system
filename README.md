# Airline E-Ticketing System

## Project Overview
This project is an academic Information Systems project that presents the design and documentation of an Airline E-Ticketing System.  
The system aims to simplify airline ticket booking, payment processing, and reservation management through an electronic platform.

## Project Contents
- System description and objectives  
- Functional and non-functional requirements  
- System diagrams (such as use case and process flow diagrams)  
- Project documentation report
